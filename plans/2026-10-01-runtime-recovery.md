# Private runtime repair correction

The ecosystem review reproduced a system interpreter being mistaken for the
private environment because both executable paths resolved to the same file.
The owner authorized this correction and, after validation, the Rubric/Loom
release pair. Quiz products and hosted spaces remain outside this work.

Use the active prefix and the base prefix to identify a private environment;
install through its explicit interpreter. Preserve the existing one-time
bootstrap, confirmation, exact dependency lock, and restart behavior.

Regression coverage uses real base, sibling, designated, and fresh temporary
environments. Installer subprocesses are intercepted; tests do not need network
access or permission to modify system packages. Native macOS and Windows checks
complement the full Linux/Python matrix and Workbench vendor-integrity check.

No vendored producer, schema, scoring rule, template meaning, or XML behavior
changes. Release preparation must retain the existing progress-contract hold.
