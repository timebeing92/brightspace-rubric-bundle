# Rubric Loom Bundle v1.3.1

This compatibility release allows a managed Rubric Loom runner to keep mutable
user work outside replaceable program versions.

## What changed

- `RUBRIC_LOOM_USER_DATA` can select the persistent root for inputs, outputs,
  remembered choices, logs, and the release-check cache.
- `RUBRIC_LOOM_VENV` can select the private Python environment used by the
  terminal Loom. First-time setup passes that exact path to the existing
  bounded bootstrapper.
- With no environment overrides, the standalone bundle behaves exactly as
  before and continues to use its repository-local `.venv`, `input/`, and
  `output/` lanes.
- The macOS bundle launcher now initializes its success-message color in both
  color and plain modes.

## Boundaries

Rubric extraction, normalization, scoring, XML construction, package
validation, and Brightspace-facing outputs are unchanged. The new paths affect
only installation layout and mutable presentation state.

This bundle remains the technical producer for Workshop and CLI consumers.
Ordinary colleague-facing downloads will be published separately through
`brightspace-rubric-loom-runner`.
