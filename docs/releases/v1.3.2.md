# Rubric Loom Bundle v1.3.2

This release makes first launch clearer and moves setup to the actual front
door.

## What changed

- A guided launch now checks the private Python environment immediately after
  the Loom artwork and before the user chooses Unravel or Weave.
- Missing dependencies are therefore explained and offered for installation
  before any file or folder path prompt.
- The setup card distinguishes an already installed Python interpreter from
  the Loom's private environment and support packages. It states explicitly
  that Python itself will not be reinstalled.
- The landing card states the product boundary directly: Rubric Loom is
  purely deterministic software running locally in Python, and no AI model
  reads or interprets the user's files.
- The README now leads a new user through the managed download, first launch,
  macOS **Privacy & Security** authorization when required, Unravel and Weave,
  and the manual Brightspace steps after a successful run.
- Technical architecture, provenance, schema, headless, testing, and release
  information remain available for maintainers and reviewers.

## Boundaries

Rubric extraction, normalization, scoring, XML construction, package
validation, and Brightspace-facing outputs are unchanged. The dependency
check has moved earlier in the existing guided flow; it still installs only
the pinned lock into the Loom's private environment.
