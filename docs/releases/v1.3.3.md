# Rubric Loom Bundle v1.3.3

This maintenance release closes two gaps in the reusable private runtime and
editable-template handoff introduced by the preceding local candidate.

## What changed

- Each launch now audits installed distribution versions against every exact
  pin in `requirements-lock.txt`. Missing or drifted packages trigger the same
  bounded private-environment repair; packages are never installed into the
  system Python.
- The editable Word and Markdown templates again lead with an explicit
  instruction to replace the synthetic title, criteria, levels, scores,
  weights, and descriptions while retaining the multi-rubric guidance.
- The Workbench-owned template manifest carries the synthetic starter-title
  completion sentinel. After producer preflight, Weave refuses a source that
  still reports that title, including a Word no-op save that changed ZIP bytes
  without changing visible rubric content.
- Template integrity metadata is pinned to Workbench commit
  `a00fc4eca1834070f5208e03f4405dea9f87ad7f`.

## Boundaries

Rubric parsing, scoring policy, Brightspace XML construction, package
validation, and manual import and attachment boundaries are unchanged. This
candidate prepares local release artifacts only; publication remains a
separate operator action.
