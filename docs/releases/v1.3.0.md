# Rubric Loom Bundle v1.3.0

This release makes the terminal Rubric Loom substantially easier to navigate
while keeping its Brightspace work deterministic, local, and review-first.

## What changed

- The opening screen now presents **Unravel** and **Weave** as the two explicit
  starting choices, with the loom artwork visible immediately.
- Unravel offers **Single export**, **Bulk folder**, and **Demonstration**
  near the beginning of the journey. Bulk mode can process a folder containing
  course-export ZIP files and unpacked export folders.
- Source selection is direct: drag or type a path, use `b` to go back, or use
  `e` to exit. Demonstration guidance no longer follows the user through every
  screen.
- Successful Unravel runs end with a styled result card that reports the
  number and names of extracted rubrics and can open the containing folder.
- The flow, spacing, instructions, remembered paths, filenames, and output
  decisions have been revised to match the clearer Blueprint Wizard pattern.
- The README and terminal artwork now present **Rubric Loom** as two words,
  with the loom palette aligned more closely to the web application.

## Provenance and release controls

- The pinned Workbench producer now preserves its exact Git commit in
  detached-HEAD environments such as GitHub Actions. A detached checkout
  records a null branch reference without discarding the commit identity.
- The bundle promotes 36 checksum-recorded Workbench files from
  `60d81c9ce7d4518111443d03cf854b584644c3cc`, with accepted producer identity
  and semantics at `71552e912b79d73a00b4d70fd97bd32386fbe2a4`.
- Tag publication now verifies the annotated tag and `VERSION`, checks the
  Workbench pin, runs the complete test suite, builds the deterministic archive
  and checksum sidecar, verifies the checksum, retains the assets with the
  workflow run, and only then creates the GitHub release.

## Boundaries

Rubric Loom does not import anything into Brightspace or attach a rubric to an
activity. Unravel reads course exports; Weave builds a rubric-only import
package after explicit review and approval. Activity attachment remains a
manual Brightspace step.
