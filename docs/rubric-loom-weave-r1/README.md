This directory records the additive Weave promotion, terminal incorporation,
release, and downstream handoff.

1. `00_PROMOTION_AND_PIN.md` — baseline before production changes
2. `01_WEAVE_ORCHESTRATOR.md` — byte pin, orchestration, progress, receipts
3. `02_TUI_INCORPORATION.md` — two-door terminal journey
4. `03_LOCAL_VERIFICATION.md` — complete bundle test and artifact evidence
5. `04_RELEASE_EVIDENCE.md` — version, asset, sidecar, public verification
6. `05_ADVERSARIAL_REVIEW_AND_HANDOFF.md` — final bundle disposition
7. `06_V1_2_0_TEMPLATE_RELEASE_CANDIDATE.md` — additive template promotion,
   source-binding repair, and local v1.2.0 candidate evidence
8. `07_V1_2_1_HOSTED_IDENTITY_REPAIR.md` — hosted receipt provenance defect,
   upstream repair, v1.2.1 release gate, and downstream redisposition

Items 04 and 05 preserve the immutable v1.1.0 history. Item 06 records the
subsequent additive v1.2.0 release. Item 07 preserves v1.2.0 unchanged while
cutting the provenance-only v1.2.1 successor.

Workbench remains the semantic owner. This repository owns pinned
distribution, process orchestration, terminal presentation, and release
identity. Nothing in this lane authorizes production-course use or automatic
activity attachment.
